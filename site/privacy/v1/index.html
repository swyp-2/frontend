개인정보 처리방침

버전 1 · 시행일 2026년 11월 16일

BATON 팀(이하 “운영자”)은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 관련 고충을 신속히 처리하기 위해 다음과 같이 개인정보 처리방침을 둡니다.

1. 처리 목적

  1. 회원 가입과 로그인, 본인 계정 식별
  2. 매장·구성원 관리와 근무표 제공
  3. 대타 요청의 전달·처리와 결과 알림 표시
  4. 문의 응대, 부정 이용 방지, 서비스 안정성 확보

2. 처리하는 개인정보 항목

구분항목수집 방법
필수 소셜 로그인 제공자(Google·Apple) 종류와 그 제공자가 발급한 회원 고유 식별자 로그인 시 제공자가 발급한 인증 정보에서 추출
필수 이름(서비스 표시 이름), 가입 역할(매니저·크루원) 가입 화면에서 이용자가 입력·선택
필수 매장 이름, 매장 소속·역할·표시 색상, 근무 일정, 대타 요청과 그 처리 기록, 앱 안 알림 기록 서비스 이용 과정에서 생성
필수 약관 동의 기록, 로그인 세션 정보 가입·로그인 과정에서 생성
자동 생성 접속 기록(IP 주소, 접속 일시) 서버 접속 시 로그로 생성

운영자는 이메일 주소, 전화번호, 소셜 계정의 프로필 사진을 저장하지 않습니다. Google·Apple 로그인 과정에서 전달되는 이메일 정보도 저장하지 않습니다.

3. 보유·이용 기간

  1. 회원 정보와 서비스 이용 기록은 탈퇴할 때까지 보유합니다.
  2. 앱 안 알림 기록은 생성 후 7일이 지나면 삭제합니다.
  3. 접속 기록은 보안·장애 대응을 위해 최대 3개월 보관한 뒤 삭제합니다.
  4. 관련 법령에 따라 보존해야 하는 정보는 그 법령이 정한 기간 동안 보관합니다.

4. 파기 절차와 방법

탈퇴하면 소셜 계정 연결 정보, 로그인 세션, 약관 동의 기록을 즉시 삭제하고 이름을 지웁니다. 매장 근무표와 대타 요청 기록처럼 다른 구성원의 기록과 함께 남아야 하는 정보는 탈퇴한 이용자를 알아볼 수 없도록 “탈퇴한 구성원”으로 바꿔 남깁니다. 전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

5. 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 서비스 특성상 같은 매장에 속한 구성원에게는 이용자의 이름, 역할, 표시 색상, 근무 일정과 대타 요청 내용이 보입니다. 법령에 따라 수사기관 등이 적법한 절차로 요구하는 경우에는 예외로 합니다.

6. 처리 위탁

수탁자위탁 업무
Amazon Web Services, Inc.서버와 데이터베이스 운영(데이터 보관 위치: 대한민국 서울 리전)

Google·Apple 로그인은 이용자가 각 제공자에게 직접 인증하는 방식이며, 운영자는 제공자가 발급한 인증 결과만 받아 확인합니다.

7. 국외 이전

운영자는 이용자의 개인정보를 국외로 이전하지 않습니다.

8. 이용자의 권리와 행사 방법

  1. 이용자는 언제든지 자신의 개인정보 열람·정정·삭제·처리정지를 요구할 수 있습니다.
  2. 이름과 소속 정보는 앱에서 확인할 수 있고, [프로필 → 계정 설정 → 탈퇴하기]로 언제든 탈퇴(삭제)할 수 있습니다.
  3. 그 밖의 요구는 아래 연락처로 보내 주시면 지체 없이 처리합니다.

9. 만 14세 미만 아동

서비스는 만 14세 미만 아동의 가입을 받지 않으며, 아동의 개인정보를 수집하지 않습니다.

10. 안전성 확보 조치

  1. 앱의 로그인 토큰은 기기의 보안 저장소(iOS 키체인)에 보관합니다.
  2. 데이터베이스는 외부에서 직접 접근할 수 없게 하고, 운영자만 접근할 수 있도록 권한을 제한합니다.
  3. 개인정보를 처리하는 인원을 최소한으로 제한합니다.

11. 자동 수집 장치

앱은 쿠키, 광고 식별자, 행동 분석 도구를 사용하지 않습니다.
